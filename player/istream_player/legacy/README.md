# Legacy player modules

Not registered by the player composer. Kept so old experiments can be read, not so new runs import them.

- `abr/` — old ABR controllers. They depend on a buffer manager that is no longer wired.
- `fast_complete_policy.py` — unused UCB early-exit policy. Live fast-complete lives on the enhancer.
- `network_manager.py` — old NetEm helper with a broken import path.
