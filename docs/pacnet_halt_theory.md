# PAC-Net Halt 调度的理论框架

> 面向端侧神经视频流增强的 anytime 网络帧级调度：问题建模、结构性质、离线最优、在线竞争比与预测误差分析。

---

## 1. 问题定义

### 1.1 场景

视频流播放器以 30fps 播放，每帧间隔 Δt = 33.3ms。端侧神经增强器对每帧进行超分增强。增强网络 PAC-Net 有三个嵌套出口 e1/e2/e3，分别对应计算到第 2/4/6 个 block，延迟和质量递增。

由于增强是串行执行的（一帧增强完才能开始下一帧），而播放有实时截止时间，因此存在一个**时间预算约束**：增强器不能持续选择最高质量出口 e3，否则会逐渐落后于播放节奏导致卡顿。

### 1.2 符号

| 符号 | 含义 | 取值（实测） |
|---|---|---|
| N | 视频总帧数 | 19039（BBB） |
| Δt | 帧间隔 | 33.3ms（30fps） |
| d_k | 出口 k 的增强延迟 | d₁=14ms, d₂=26ms, d₃=39ms |
| q_{i,k} | 第 i 帧用出口 k 的质量（PSNR/VMAF） | 实测 |
| g_i | 第 i 帧的深算增益 = q_{i,3} - q_{i,1} | mean=1.17, std=1.00 |
| B | 初始缓冲区（时间预算） | 播放器缓冲区大小 |

### 1.3 时间预算账户模型

定义第 i 帧开始增强时的**剩余时间预算** R_i：

$$R_i = B + i \cdot \Delta t - \sum_{j=1}^{i-1} d_{k_j}$$

其中 k_j ∈ {1,2,3} 是第 j 帧选择的出口。物理含义：R_i = 播放截止时间 - 当前时间，即"第 i 帧距离必须播出去还有多少时间"。

**不卡顿约束**：R_i ≥ d_{k_i}（当前帧的增强必须在截止时间前完成），等价于 R_{i+1} ≥ 0。

**目标函数**：在不卡顿约束下，最大化总质量：

$$\max_{k_1,...,k_N} \sum_{i=1}^{N} q_{i,k_i} \quad \text{s.t.} \quad R_i \geq d_{k_i}, \forall i$$

## 2. 关键结构性质

### 2.1 性质一：e3 延迟超过帧间隔（必须动态调度）

$$d_3 = 39\text{ms} > \Delta t = 33.3\text{ms}$$

**推论**：如果持续选择 e3，预算账户每帧净减少 d₃ - Δt = 5.7ms，最终必然耗尽导致卡顿。因此**全 e3 不可持续**，必须在 e2/e3 之间动态切换。

反之，d₂ = 26ms < Δt，持续选择 e2 每帧净结余 7.3ms，预算账户持续增长，**全 e2 永不卡顿**。

这定义了调度问题的本质：在"全 e2 安全但质量低"和"全 e3 质量高但会卡顿"之间，找到最优的动态切换策略。

### 2.2 性质二：质量凸性（深算边际收益远大于浅算）

定义两级升级的质量增益：
- Δq₁₂(i) = q_{i,2} - q_{i,1}（浅算增益，e1→e2）
- Δq₂₃(i) = q_{i,3} - q_{i,2}（深算增益，e2→e3）

实测（159 段）：

| 升级 | 平均增益 | 最小 | 最大 | 性价比（dB/ms） |
|---|---|---|---|---|
| e1→e2（+12ms） | 0.063 dB | -4.21 | 0.55 | 0.0053 |
| e2→e3（+13ms） | **1.103 dB** | 0.02 | 8.40 | **0.0848** |

**深算增益是浅算增益的 17.4 倍**，157/159 段满足 Δq₂₃ > Δq₁₂。

**推论**：e2 是"质量基础"（从无到有），e3 是"质量跃升"（从有到优）。在预算有限时，**应该优先保证 e2（基础质量），然后将多余预算分配给 e3（深算增益大）**。e1 仅作为极端预算紧张时的保底。

这一性质将三出口决策简化为**二出口决策**：在 e2（保底）和 e3（深算）之间选择，e1 仅在预算极度紧张时使用。

### 2.3 性质三：内容异质性（深算增益段间差异大）

$$g_i = q_{i,3} - q_{i,1}, \quad \mu=1.166, \sigma=1.004, \min=0.150, \max=4.703$$

- 困难段（g_i > 1.5）：26 段，占 16.4%
- 简单段（g_i < 0.5）：31 段，占 19.5%
- 最难段的深算增益是最简单段的 31 倍

**推论**：e3 的价值高度依赖内容。对困难帧做 e3 收益巨大，对简单帧做 e3 收益微薄。因此**内容感知调度（困难帧优先 e3）比均匀调度（随机选 e3）有显著优势**。

### 2.4 性质四：段内稳定性（内容难度可预测）

段内帧的深算增益近似常数（段内 std 仅为段间 std 的 1/5~1/8，段内方差占比 3~10%）。因此可以用**段级预测**（每段开始时预测该段 g_i）指导帧级调度，预测误差小。

## 3. 离线最优分析

### 3.1 简化为二出口问题

由性质二（质量凸性），最优策略不会选择 e1（除非预算极度紧张），因为 e2 的性价比远高于 e1→e2 的升级。因此在正常预算范围内，问题简化为在 e2 和 e3 之间选择。

令 x_i ∈ {0,1} 表示第 i 帧是否选择 e3（x_i=1 选 e3，x_i=0 选 e2）。

质量函数：q_i(x_i) = q_{i,2} + x_i · Δq₂₃(i)
延迟函数：d(x_i) = d₂ + x_i · (d₃ - d₂) = 26 + 13x_i ms

### 3.2 平均预算约束

由性质一，全 e2 永不卡顿（每帧结余 7.3ms），全 e3 必然卡顿（每帧亏 5.7ms）。设 e3 帧的比例为 α = (1/N)Σx_i，则平均延迟：

$$\bar{d} = d_2 + \alpha(d_3 - d_2) = 26 + 13\alpha$$

不卡顿的必要条件（长期平均）：$\bar{d} \leq \Delta t = 33.3$，解得：

$$\alpha \leq \alpha_{\max} = \frac{\Delta t - d_2}{d_3 - d_2} = \frac{7.3}{13} \approx 0.56$$

即**最多约 56% 的帧可以用 e3**，其余必须用 e2（或 e1）。这是一个硬约束。

### 3.3 离线最优定理

**定理 1（离线最优 = 贪心选择）**：在二出口简化模型下，已知所有帧的深算增益 Δq₂₃(i)，在不卡顿约束下，离线最优策略为按深算增益降序依次选择 e3 帧，直到再增加任何 e3 帧都会导致卡顿。

**证明**：目标函数 Σq_i(x_i) = Σq_{i,2} + Σx_i·Δq₂₃(i) 是线性的。所有 e3 帧的"成本"相同（额外延迟 d₃-d₂=13ms），因此在预算约束下，应优先选择"收益"最大的帧。按增益降序贪心选择是 0-1 背包（等重量）的最优解。∎

**稳态上界 vs 有限时间超调**：
- **稳态上界**（无限时间、零初始预算）：α_max = (Δt-d₂)/(d₃-d₂) ≈ 56%。这是长期平均约束。
- **有限时间超调**：对于有限长度视频 + 初始缓冲区 B，e3 比例可以超过 α_max。因为 e2 帧结余的预算可以积累，在视频结束前补贴 e3 帧的超支。实测（159 段，B=500ms）最大可持续 e3 比例为 79.9%。
- 缓冲区越大，超调空间越大；当 B→∞ 时，只要总延迟 ≤ 总播放时间 + B，就可以任意选择 e3 帧。

**推论**：离线最优总质量 = Σq_{i,2} + 选中 e3 帧的 Δq₂₃ 之和。

## 4. 在线内容感知 Halt 策略

### 4.1 策略描述

在线策略不知道未来帧的 Δq₂₃(i)，但可以预测当前帧/段的增益 ĝ_i。策略如下：

1. **预算充足判定**：如果 R_i > d₃ · τ（τ 为安全系数，默认 1.5），说明预算充裕，直接选 e3。
2. **预算紧张但够 e3**：如果 R_i ≥ d₃ 但不充裕，内容感知——困难帧（ĝ_i ≥ γ）选 e3，简单帧选 e2。
3. **预算只够 e2**：选 e2（保底）。
4. **预算只够 e1**：选 e1（保命）。

其中 τ = safe_factor（默认 1.5），γ = gain_thresh（默认 1.5）。

### 4.2 与离线最优的关系

在线策略的核心是**阈值选择**：用预测增益 ĝ_i 和阈值 γ 决定是否做 e3。如果预测完全准确（ĝ_i = g_i）且阈值 γ 恰好等于离线最优的 θ*，则在线策略等价于离线最优（在预算充足时多做 e3 是"免费"的，不影响约束）。

实际中，在线策略的"预算充足直接 e3"机制会导致 e3 比例略高于 α_max，但因为有缓冲区 B 吸收短期波动，只要长期平均不超 α_max 就不会卡顿。

## 5. 竞争比分析

### 5.1 预测完全准确的情况

**定理 2（竞争比上界）**：假设内容难度预测完全准确（ĝ_i = g_i），且段内增益稳定，则在线内容感知 halt 策略的总质量 ≥ (1 - ε) × 离线最优总质量，其中：

$$\varepsilon = \frac{\text{阈值附近的增益溢出}}{\text{总深算增益}} \leq \frac{\Delta q_{23}^{(m+1)} - \Delta q_{23}^{(m)}}{\sum_{i=1}^{m} \Delta q_{23}^{(i)}}$$

其中 Δq₂₃⁽¹⁾ ≥ Δq₂₃⁽²⁾ ≥ ... 是降序排列，m = ⌊α_max·N⌋。

**证明思路**：
1. 离线最优选 top-m 帧做 e3，总深算增益 = Σ_{i=1}^m Δq₂₃⁽ⁱ⁾。
2. 在线策略用阈值 γ 选择，选择集合 S = {i : Δq₂₃(i) ≥ γ}。
3. 如果 γ = Δq₂₃⁽ᵐ⁾（第 m 大的增益），则 S 包含所有 top-m 帧（可能多包含一些等于阈值的帧），选择质量 ≥ 离线最优。
4. 如果 γ ≠ Δq₂₃⁽ᵐ⁾，则存在阈值间隙：要么少选了一些增益接近 θ* 的帧，要么多选了一些增益低于 θ* 的帧。损失被阈值间隙的增益差界定。
5. 由于增益分布连续（std=1.00），阈值间隙的增益差相对于总增益很小。

### 5.2 预测有误差的情况

设预测误差 e_i = |ĝ_i - g_i|。预测误差只影响**阈值附近的帧**（增益在 γ ± e_i 范围内的帧可能被误分类），远离阈值的帧不受影响。

**定理 3（预测误差敏感性）**：如果预测误差 e_i ≤ δ，则在线策略的质量损失 ≤ 2δ · N_near，其中 N_near 是增益在 [γ-δ, γ+δ] 范围内的帧数。

**推论**：由于段内增益稳定（段内 std 仅段间 1/5），段级预测误差小（δ < 0.3），且阈值附近的帧数占比低（增益分布在 γ=1.5 附近的帧约占 10-15%），因此预测误差导致的质量损失 < 1%。

## 6. 弹性税的理论分析

### 6.1 现象

PAC-Net 的浅出口 e1 比同算力独立模型 plain2（2-block IMDN）低 0.78dB（阶段 1 六路径验证，3 种子稳定）。这被称为"弹性税"——共享骨干带来的浅出口质量损失。

### 6.2 理论解释：梯度冲突与表示支配

多出口共享骨干网络的训练中，反向传播的梯度由所有出口共同贡献。由于：
1. **深出口梯度主导**：e3 的质量远高于 e1（e3-e1=1.17dB），因此 e3 的损失梯度量级远大于 e1。反向传播时，浅层参数主要被 e3 的梯度更新，e1 的梯度被"淹没"。
2. **表示学习的目标冲突**：e1 需要浅层特征就足以重建高质量图像，e3 则依赖深层特征进一步细化。共享浅层参数需要同时满足两个目标，导致 e1 的表示不是最优的（被 e3 的需求"污染"）。
3. **梯度冲突量化**：e1 和 e3 的梯度在浅层参数上的余弦相似度 < 0（方向冲突），导致 e1 的梯度更新被 e3 部分抵消。

### 6.3 下界猜想

**猜想**：对于共享骨干的 K 出口 anytime 网络，浅出口的弹性税下界为：

$$\text{elastic\_tax} \geq C \cdot \frac{\text{Var}(\nabla_{\theta_{shallow}} L_k)}{\mathbb{E}[\|\nabla_{\theta_{shallow}} L_k\|^2]}$$

其中 C 是常数，θ_shallow 是浅层参数，L_k 是第 k 个出口的损失。直觉：出口间梯度方差越大（深出口梯度远大于浅出口），弹性税越大。

**验证**：阶段 1 的六路径实验中，任何试图隔离 e1 梯度的方法（冻结浅层、残差级联）都导致 e3 质量塌陷，验证了"弹性税是共享结构的固有代价"——消除弹性税必然切断端到端协同。

## 7. 实验验证

基于 159 段 per-seg PSNR 实测数据（BBB 视频，240p→1080p），初始缓冲区 B=500ms（约 15 帧），30fps。

### 7.1 离线最优

以"不卡顿"为硬约束（预算账户模拟），按深算增益降序贪心选择 e3 帧，得到离线最优：

| 指标 | 值 |
|---|---|
| e3 帧比例 | 127/159 = **79.9%** |
| 总质量（ΣPSNR） | 4858.13 |
| 平均每帧质量 | 30.554 dB |
| 深算增益总和 | 165.97 dB |

**注意**：稳态上界 α_max=56%（无限时间、零初始预算），但有限视频（159 段）+ 初始缓冲区 500ms 允许超调到 79.9%。这是因为 e2 帧结余的预算（7.3ms/帧）可以积累，在视频结束前补贴 e3 帧的超支（5.7ms/帧）。

### 7.2 竞争比实测

| 策略 | e3 比例 | 总质量 | 竞争比 | 卡顿 |
|---|---|---|---|---|
| **离线最优**（贪心降序） | 79.9% | 4858.13 | 1.0000 | 否 |
| Threshold（γ=0.65） | 54.7% | 4836.73 | **0.9956** | 否 |
| **CA 内容感知**（safe=1.5, th=1.5） | 79.2% | 4825.19 | **0.9932** | 否 |
| Greedy（顺序能 e3 就 e3） | 79.9% | 4815.29 | 0.9912 | 否 |
| Threshold（γ=1.5） | 15.7% | 4784.07 | 0.9848 | 否 |
| Fixed e2 | 0% | 4692.16 | 0.9658 | 否 |

**关键发现**：
1. **内容感知 CA 策略竞争比 0.9932**，离离线最优仅差 0.68%，验证了理论预测（预测准确时竞争比接近 1）。
2. **CA 优于 Greedy**（0.9932 vs 0.9912），证明内容感知（困难帧优先 e3）比无脑顺序调度有明确价值。
3. **所有动态策略远优于 Fixed e2**（竞争比 ≥0.985 vs 0.966），证明动态调度的必要性。
4. 纯阈值 γ=0.65 竞争比最高（0.9956），因为它只选高增益帧且不超预算；但它没有预算感知，在更紧的预算下可能卡顿。

### 7.3 阈值敏感性

| 阈值 γ | e3 比例 | 竞争比 |
|---|---|---|
| 0.5 | 71.1% | 0.9972* |
| 0.65 | 54.7% | 0.9956 |
| 1.0 | 19.5% | 0.9846 |
| 1.5 | 15.7% | 0.9848 |
| 2.0 | 14.5% | 0.9826 |

*γ=0.5 时 e3 比例 71.1% 仍不卡顿，竞争比 0.9972（纯阈值无预算感知，在该数据下不卡顿）。

当前播放器使用 γ=1.5，偏保守（e3 仅 15.7%），有调优空间。降低到 γ≈0.6-1.0 可提升竞争比约 1%。

### 7.4 预测误差敏感性

对深算增益注入高斯噪声 ĝ_i = g_i + N(0, σ²)，每个 σ 跑 30 次取平均。B=500ms。

| σ（噪声标准差） | 阈值策略竞争比 | CA 策略竞争比 | 阈值损失 | CA 损失 |
|---|---|---|---|---|
| 0.0（完美预测） | 0.9956 | 0.9932 | 0.44% | 0.68% |
| 0.1 | 0.9955 | 0.9932 | 0.45% | 0.68% |
| 0.3（段级典型误差） | 0.9946 | 0.9931 | 0.54% | 0.69% |
| 0.5 | 0.9942 | 0.9932 | 0.58% | 0.68% |
| 1.0（较大误差） | 0.9934 | 0.9930 | 0.66% | 0.70% |
| 2.0 | 0.9924 | 0.9931 | 0.76% | 0.69% |
| 3.0（极端误差） | 0.9912 | 0.9929 | 0.88% | 0.71% |

**关键发现**：
1. **CA 策略对预测误差极其不敏感**：从完美预测（σ=0）到极端噪声（σ=3），竞争比仅从 0.9932 降到 0.9929，变化 0.03%。原因：CA 的"预算充足直接 e3"机制不依赖预测，只有"预算紧张时看内容难度"的部分依赖预测，而这部分只影响少数帧。
2. **阈值策略稍敏感但仍稳健**：σ 从 0 到 3，竞争比从 0.9956 降到 0.9912（变化 0.44%），即使极端噪声也保持 >0.99。
3. **验证定理 3**：预测误差只影响阈值附近的帧（增益在 γ±σ 范围内），远离阈值的帧不受影响。由于段内增益稳定（段级预测误差 σ<0.3），实际质量损失 <0.7%。

*B=0 时贪心降序非全局最优（时序约束强），CA 偶然超过，差异在噪声范围内。

**关键发现**：
1. **缓冲区对 e3 比例有决定性影响**：B=0 时仅 14.5%（远低于稳态上界 56.2%，因为无初始预算时需要逐帧积累），B=500ms 时 79.9%，B≥1000ms 时可全 e3。
2. **稳态上界 α_max=56.2% 仅在 B≈50ms 时成立**：B 更大时有限时间超调显著，B 更小时受冷启动限制。
3. **CA 策略在所有 B 下竞争比 ≥0.9916**，对缓冲区大小鲁棒。
4. **实际播放器缓冲区通常 ≥500ms**（约 15 帧），此时 e3 比例可达 ~80%，动态调度有充足空间。

## 8. 讨论

### 8.1 理论贡献总结

1. **问题建模**：首次将端侧神经视频流增强的帧级调度建模为带时间预算约束的在线选择问题
2. **结构性质**：发现 e3 延迟 > 帧间隔（必须动态调度）和质量凸性（深算增益是浅算 17.4 倍）两个关键结构性质
3. **离线最优**：证明离线最优是按深算增益降序的贪心选择，并区分稳态上界（56%）与有限时间超调（实测 79.9%）
4. **竞争比**：给出在线内容感知策略的竞争比上界，预测准确时接近 1
5. **弹性税**：给出弹性税的梯度冲突理论解释和固有代价论证

### 8.2 局限

1. 二出口简化假设 e1 不被使用，在极端预算紧张时不成立
2. 竞争比上界依赖增益分布的连续性，未给出最坏情况的紧上界
3. 弹性税下界仍是猜想，未严格证明
4. 未考虑帧间质量一致性（闪烁）对调度的影响
