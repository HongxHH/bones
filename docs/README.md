# 项目文档导航

## 文档维护规则

1. **一文件一主题**：每个文件只覆盖一个明确主题，不写跨主题内容
2. **不冗余**：两个文件内容重叠时，合并为一个；操作类信息只在 `quick_start.md` 写，其他文件引用不重复
3. **新增文件前先查**：确认现有文件没有覆盖该主题，再新增；新增时在本 README 加一行导航
4. **数据可追溯**：实验结果标注时间戳和配置参数，不写"大概""可能"
5. **代码引用精确到行**：提到代码时写 `文件路径:行号`，不写"在某某文件里"
