# 服务端内容感知VBR编码

> **状态：已证伪封板（2026-10-09 复核）。本文全部正面结论作废，仅作踩坑记录保留。**
> 作废原因：① 二值/平方根/4 档 VBR 数据平均超支 +16.3%~+18.2% 字节，增益主要靠多花码率；② "决策后应用 VBR 提升"（方式三）不下载额外字节、不改变卡顿，是物理不可实现的反事实；物理可实现的方式一/二端到端为 −0.06/−0.71。严格等码率判决（TOS+BBB、LP oracle）见 `docs/sr_aware_alloc_falsification.md`：内容感知逐段分配上限 0.75~2.08 VMAF、平方根方向与最优分配反向（Spearman −0.85~−0.93）。完整审计见 `workspace/vbr_sims/vbr/README.md`（档案 #7）。

## 核心思路

传统视频流系统（包括BONES）假设服务端提供CBR（固定码率）码流，客户端只做ABR码率选择。本方向验证：服务端根据视频内容特征（运动强度），对高运动段分配更高码率，能否在不影响客户端ABR决策的前提下提升播放质量。

**VBR策略**：60%高运动段码率提升25%，其他40%段保持基础码率。

## 三种集成方式对比（6条轨迹，BONES算法）

### 方式一：改文件大小+改VMAF（直接替换manifest和enhance）

| 指标 | 结果 |
|------|------|
| QoE差异 | -0.06 |
| VMAF差异 | +0.56 |
| 卡顿差异 | +71ms |

**问题**：文件大小变化影响ABR决策，VMAF提升被卡顿增加抵消。

### 方式二：只改VMAF（文件大小不变，只改enhance中的base_quality）

| 指标 | 结果 |
|------|------|
| QoE差异 | -0.71 |
| VMAF差异 | -0.03 |
| 卡顿差异 | +693ms |

**问题**：质量感知变化导致BONES选择更低码率档，最终质量反而下降，卡顿大幅增加。

### 方式三：决策后应用VBR提升（ABR决策用CBR数据，决策后对质量应用提升量）✅

| 指标 | 4G | 3G | 总体 |
|------|-----|-----|------|
| QoE提升 | +1.20 | +1.25 | **+1.22** |
| VMAF提升 | +0.83 | +1.21 | **+1.02** |
| 振荡变化 | -0.38 | -0.03 | **-0.21** |
| 卡顿变化 | 0ms | 0ms | **0ms** |

**关键**：ABR决策、文件大小、下载时间、缓冲区行为、卡顿完全保持CBR不变，只有最终播放质量得到VBR提升。

## 阶段二：连续码率分配优化（2026-08-31，已修正）

### 测试的分配策略

| 策略 | 平均码率提升 | 480p VMAF提升 | 全轨迹QoE提升 | 全轨迹振荡变化 |
|------|------------|---------------|--------------|--------------|
| 二值分配（基线） | +14.9% | +1.18 | +1.21 | -0.14 |
| **平方根分配** ✅ | +16.6% | +1.29 | **+1.70** | **-0.19** |
| 4档分配 [5%,10%,20%,30%] | +16.3% | +1.24 | +1.60 | -0.11 |

### 核心发现：平方根分配最优（修正后）

**重要修正**：阶段二最初结论"二值分配最优"是错误的，因为1080p处理有bug——CBR的1080p质量用BONES假设的100，VBR的1080p质量用实际VMAF 94.31+提升量，导致VBR质量反而更低，振荡被高估。

修复bug后（CBR和VBR的1080p质量都用实际VMAF），结果完全反转：

1. **平方根分配全面最优**：QoE提升+1.70（比二值高+0.49，提升40%），VMAF提升+1.52（比二值高+0.44），振荡减少-0.19（比二值多减-0.05）
2. **4档分配次之**：QoE提升+1.60，VMAF提升+1.49，振荡减少-0.11
3. **二值分配最差**：QoE提升+1.21，VMAF提升+1.08，振荡减少-0.14
4. **3G场景优势最明显**：平方根分配QoE +1.95 vs 二值 +1.22（提升60%）；4G场景差异较小（+1.22 vs +1.20）
5. **MD-QoE（多维度QoE）同样验证**：平方根分配MD_QoE +0.82 vs 二值 +0.56（提升46%）

### 为什么平方根分配最优？

1. **码率-VMAF曲线非线性**：低码率区域VMAF对码率更敏感，平方根分配给低运动段更多码率（相对于二值的0提升），整体VMAF更高
2. **连续变化减少振荡**：平方根分配的码率随运动强度连续变化，相邻段码率差异小；二值分配在60%/40%边界处有+25%/0%的跳变
3. **高运动段仍有足够提升**：平方根分配最高提升约+30%（比二值的+25%更高），高运动段质量更好
4. **平均码率更高**：平方根分配平均码率提升+16.6%（比二值的+14.9%高），但因为是"决策后应用提升"，不影响ABR决策和下载行为

### 阶段二结论（修正后）

**平方根分配是最优策略**。连续的码率分配（平方根）比简单的二值分配更好，因为它在VMAF提升更高的同时，振荡也更少。之前"更细粒度不一定更好"的结论是由于1080p处理bug导致的误判。

这是一个有价值的工程发现：**在VBR编码中，基于内容复杂度的连续码率分配（平方根函数）比简单的二值分配更优，因为它同时实现了更高的VMAF和更少的振荡。**

## 核心发现

1. **VBR编码本身有价值**：131条真实网络轨迹100%胜率，平均QoE +1.21（二值）~ +1.70（平方根）、VMAF +1.08~+1.52，效果显著且极其稳定
2. **集成方式至关重要**：直接修改manifest/enhance会改变ABR的质量感知和文件大小，导致适得其反；正确方式是VBR对ABR透明，决策后应用提升
3. **1080p数据不可或缺**：4G下BONES经常选1080p，BONES原始代码将最高码率设为满分100导致VBR提升无法体现；用实际CBR VMAF（94.31）作基准后，4G QoE从+0.07提升到+1.20
4. **振荡反而下降**：1080p实际VMAF（94.31）比满分100更接近其他码率档，减少了码率切换时的质量波动
5. **二值分配（有升有降）不可行**：码率-VMAF曲线非线性，低运动段降码率的损失大于高运动段升码率的收益；只升不降是正确策略
6. **平方根分配最优**（修正后）：基于内容复杂度的连续码率分配（平方根函数）比简单的二值分配更优，QoE提升40%（+1.70 vs +1.21），同时VMAF更高、振荡更少。之前"更细粒度不一定更好"的结论是1080p处理bug导致的误判
7. **3G场景VBR效果更显著**：平方根分配在3G场景QoE +1.95（比二值高60%），4G场景差异较小（+1.22 vs +1.20），因为4G下BONES经常选1080p，VBR提升空间有限
8. **MD-QoE验证结论一致**：自定义多维度QoE指标（感知质量+时序平滑度+卡顿体验）同样显示平方根分配最优（+0.82 vs +0.56），说明结论不依赖于BONES的QoE公式
