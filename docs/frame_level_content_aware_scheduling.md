# 帧级内容感知增强调度设计

## 1. 核心思想

BONES采用**段级决策**（每4秒/120帧决定一次码率和增强级别），假设段内所有帧的增强收益相同。但实际视频中：
- 高运动帧（场景切换、快速移动）的VMAF对增强更敏感
- 低运动帧（静态画面、慢动作）的增强收益边际递减
- 段平均VMAF掩盖了帧级的质量波动

**帧级调度**：在段级决策确定码率后，对段内每帧独立决定是否增强、用什么级别增强，将有限的GPU计算资源分配给增强收益最大的帧。

## 2. 理论框架

### 2.1 问题建模

**状态空间**：
- $B_t$：当前缓冲区占用（秒）
- $\hat{C}_t$：估计带宽（Mbps）
- $x_t$：当前帧内容特征向量 $\in \mathbb{R}^d$（运动强度、纹理复杂度、场景切换标记）
- $E_t$：当前段已用计算资源（帧·级别单位）
- $q_t$：当前帧的基础质量（无增强VMAF）

**动作空间**：
- $a_t \in \{0, 1, 2, 3\}$：0=不增强，1=SR_low，2=SR_medium，3=SR_high

**奖励函数**：
$$r_t = \Delta \text{VMAF}(a_t, x_t) - \lambda \cdot D(a_t) - \mu \cdot C(a_t)$$

其中：
- $\Delta \text{VMAF}(a_t, x_t) = f(a_t, x_t) - q_t$：增强带来的VMAF增益，**依赖内容特征**
- $D(a_t)$：增强延迟（帧时间），超过播放deadline则惩罚
- $C(a_t)$：计算资源消耗（GPU毫秒）
- $\lambda, \mu$：权衡系数

**约束**：
- 缓冲区约束：$B_t \geq B_{\min}$（不卡顿）
- 计算资源预算：$\sum_{t \in \text{segment}} C(a_t) \leq C_{\text{budget}}$（段内总GPU时间不超过段时长）
- 延迟约束：增强完成时间 $\leq$ 播放deadline

### 2.2 内容感知增益模型

从逐帧测量数据中学习增益函数：
$$\Delta \text{VMAF}(a, x) = \beta_0(a) + \beta_1(a) \cdot \text{motion}(x) + \beta_2(a) \cdot \text{texture}(x) + \beta_3(a) \cdot \text{scene\_change}(x)$$

**关键假设**（待逐帧数据验证）：
- 高运动帧：SR_medium/high的增益显著大于SR_low
- 低运动帧：SR_low的增益已接近饱和，SR_high边际收益小
- 场景切换帧：任何级别的增益都较小（参考帧刚变化，VMAF计算不稳定）

### 2.3 Lyapunov优化框架

定义虚拟队列：
- $Z_t$：计算资源赤字队列，$Z_{t+1} = \max(Z_t + C(a_t) - C_{\text{budget}}/N, 0)$
- $Y_t$：延迟积压队列，$Y_{t+1} = \max(Y_t + D(a_t) - T_{\text{frame}}, 0)$

漂移加惩罚最小化：
$$\min_{a_t} \mathbb{E}\left[V \cdot r_t + Z_t \cdot C(a_t) + Y_t \cdot D(a_t) \mid \text{state}\right]$$

其中$V$控制QoE与资源约束的权衡。

**理论保证**：
- 近最优性：QoE差距 $O(1/V)$
- 队列稳定性：$Z_t, Y_t$ 平均长度 $O(V)$
- 与BONES的Lyapunov框架兼容，可直接复用其理论分析

## 3. 算法设计

### 3.1 贪心帧级调度（基线）

每帧独立选择使即时奖励最大的动作：

```
for each frame t in segment:
    for each action a in {0,1,2,3}:
        compute r_t(a) = ΔVMAF(a, x_t) - λ·D(a) - μ·C(a)
        if resource budget exceeded: r_t(a) = -∞
    select a_t* = argmax r_t(a)
    update resource usage
```

**复杂度**：O(N) per segment，N=120帧

### 3.2 前瞻帧级调度（推荐）

利用段内所有帧的内容特征（可预提取），做全局优化：

```
# 段开始时，预提取所有帧的内容特征
x_1, x_2, ..., x_N = extract_features(segment)

# 动态规划：最大化段内总VMAF增益，受资源预算约束
# dp[i][c] = 前i帧用c资源的最大总增益
for i = 1 to N:
    for c = 0 to C_budget:
        dp[i][c] = max over a:
            dp[i-1][c - C(a)] + ΔVMAF(a, x_i)
            if c >= C(a) and deadline constraint satisfied

# 回溯得到最优动作序列
a_1*, ..., a_N* = backtrack(dp)
```

**复杂度**：O(N · C_budget · |A|)，C_budget通常为120（帧·单位），可接受

**优势**：
- 全局最优（在给定增益模型下）
- 自然处理资源约束
- 可扩展到多段联合优化

### 3.3 混合调度（工程实用）

段级用BONES决定码率和最大增强级别，帧级用前瞻调度在预算内分配：

```
1. BONES段级决策：选择码率r_seg和最大增强级别a_max
2. 预提取段内所有帧的内容特征
3. 帧级前瞻调度：在a ∈ {0, ..., a_max}和资源预算内优化
4. 逐帧执行增强决策
```

**优势**：
- 复用BONES的码率选择（经过验证的Lyapunov优化）
- 帧级只做增强资源分配（问题规模小，易求解）
- 渐进式改进，风险可控

## 4. 实现要点

### 4.1 内容特征预提取

在段下载完成后、播放前，预提取段内所有帧的内容特征：
- 运动强度：相邻帧灰度差的MSE
- 纹理复杂度：Laplacian方差
- 场景切换：运动强度超过阈值（如30.0）

特征存储在内存中，供帧级调度使用。开销：120帧×约1ms=0.12s，可忽略。

### 4.2 增益模型训练

从逐帧VMAF测量数据中拟合：
- 对每个分辨率×增强级别，拟合$\Delta\text{VMAF}(x)$的线性/非线性模型
- 简单方案：按内容特征分桶（高/中/低运动 × 高/中/低纹理），每桶取平均增益
- 高级方案：训练轻量级回归模型（如随机森林，<1MB）

### 4.3 播放器集成

修改`enhancer_multitask.py`：
- 段开始时调用帧级调度器，得到120帧的动作序列
- 播放时按动作序列逐帧增强
- 不增强的帧直接用bicubic upscale（零开销）
- 动态调整：如果实际GPU时间超出预算，跳过后续低优先级帧的增强

### 4.4 资源预算动态调整

根据当前GPU负载和缓冲区状态动态调整段内资源预算：
- 缓冲区高（>10s）：预算=段时长×1.0（充分利用）
- 缓冲区中（5-10s）：预算=段时长×0.8（留余量）
- 缓冲区低（<5s）：预算=段时长×0.5（优先保证播放）

## 5. 与BONES的对比

| 维度 | BONES段级 | 帧级内容感知 |
|------|-----------|-------------|
| 决策粒度 | 120帧/决策 | 1帧/决策 |
| 内容感知 | 无（段内均匀） | 有（运动/纹理/场景） |
| 资源分配 | 段内固定级别 | 帧间动态分配 |
| 理论保证 | Lyapunov O(1/V) | 扩展Lyapunov O(1/V) |
| 实现复杂度 | 低 | 中（需特征提取+调度器） |
| 预期增益 | 基线 | VMAF +1~3，资源利用 +10~20% |

## 6. 验证计划

1. **离线验证**：用逐帧VMAF数据，仿真帧级调度vs段级固定，计算VMAF和资源消耗
2. **仿真器验证**：在`simulation/simulator.py`中实现帧级调度，多轨迹对比
3. **播放器验证**：在iStreamPlayer中集成，实测QoE指标
4. **消融实验**：内容特征的贡献、前瞻窗口大小的影响、资源预算策略的影响
