## 关键发现

1. **VMAF 差值惩罚比级别惩罚有效**：基于级别的切换惩罚（α=2.0）oscillation 反而升到 12.06；基于 VMAF 差值的惩罚（α=0.3）oscillation 降到 3.67-3.91
2. **CARES 与 VMAF 平滑正交可组合**：CARES 影响"选什么级别"（资源效率），VMAF 平滑影响"级别是否变化"（稳定性），两者不冲突
3. **路径依赖/双稳态**：α=0.3 时出现两种稳定均衡（level1主导 vs level2主导），初始段微小差异决定路径，两种路径 QoE 都高
4. **stall 权重极低**：QoE 公式中 `avg_freeze/10`，100s stall 只扣 0.06 分，所以 stall 增加不影响 QoE 对比
